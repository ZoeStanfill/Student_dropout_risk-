# Student_dropout_risk.
https://www.kaggle.com/datasets/mohankrishnathalla/student-academic-performance-and-dropout-risk
Data Source and Attribution

The dataset used in this project was obtained from Kaggle and is attributed to Mohan Krishna Thalla, the dataset uploader.

I did not personally collect or generate the data. According to the dataset description, all records are fully synthetic and do not contain real student data.

The dataset was calibrated using research and information from the National Center for Education Statistics (NCES), UNESCO, OECD, Georgetown Center on Education and the Workforce, American College Health Association, ACT National Dropout Prevention Center, and Tinto's Student Integration Model.

Disclaimer

This project was completed for educational purposes to practice data analysis, cleaning, and visualization using Python. Any findings represent patterns in the synthetic dataset and should not be assumed to reflect real-world student outcomes.

Credit: Mohan Krishna Thalla and the original research sources acknowledged in the Kaggle dataset description.
